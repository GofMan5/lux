# Stage 9 — Slice 4: examples/ssh (LUX TUI over SSH)

Snapshot: 2026-10-09. Module: `github.com/lux-tui/lux/examples/ssh`
(nested Go module, `//go:build !windows` on all files — creack/pty has no
Windows port; the root module's `./...` does not descend into it).

## What was built

An SSH server (gliderlabs/ssh v0.3.8) that serves LUX TUI by bridging each
SSH session onto a real pty (creack/pty v1.1.24, `StartWithSize` —
`setsid` + `TIOCSCTTY`) and running the requested program there as the
session leader. Design B: the full LUX engine runs in a child process on
a genuine terminal — raw mode, capability probes, and SIGWINCH go through
the same code paths as a local terminal; the SSH layer is pure byte
plumbing. Zero changes to the library.

- `main.go` — single binary, `-child` re-exec mode (default argv is the
  binary itself), or a generic pty forwarder for any argv
  (`-- /bin/sh`, `-- ../showcase/showcase`); `-addr`, `-password` flags.
- `serve.go` — pty spawn with the client's TERM, winch goroutine
  (`TIOCSWINSZ` on every window-change), input/output pumps, context
  cancel → SIGKILL to the child's process group (session leader), exit
  status mapped to the SSH exit-status request (signal death → 1).
- `child.go` — the demo TUI: title, live pty-size readout, TERM value,
  transport line; quits on `q`/Escape.
- `README.md` — design rationale, run instructions, caveats (demo
  password auth, no signal forwarding, 0x0 ptys from piped clients).

## Notes for the record

- Two compile fixes during the slice: gliderlabs' pty request field is
  `Pty.Term`, not `Terminal`.
- Two stacked causes in the resize unit test: (a) interactive busybox
  ash blocks on an unanswered `ESC[6n`; (b) the test waited for a
  command's output before typing the command. Both fixed; the fake now
  auto-replies DSR.
- `ptmx.SetReadDeadline` is unsupported on a pty master (Read blocks
  forever) — deadlines are never used on pty fds in this module.
- The ssh wire is encrypted, so evidence is pane captures, not raw
  bytes (unlike the sshd-lane raw wire).
- `ssh-example-server.log` is gitignored (`*.log`); the pane captures
  and unit output are the committed evidence.
