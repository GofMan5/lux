Features:
  the keyboard reaches every control: Tab cycles controls a container owns
    even when a clipped region registers no hit geometry
  shortest VT encoding of a frame: SGR runs and cursor moves emit the
    shortest escape sequences the capability profile allows
  the terminal moves rows it already has: scroll detection emits a DECSTBM
    region scroll plus IL/DL and lets the terminal shift rows instead of
    repainting them; render.Buffer.ScrollRows applies the same move locally
    and the encoder re-marks the rows the terminal vacated
  terminal shutdown is bounded: once Close begins the terminal stops
    accepting input and returns within the timeout
  idle cost is one EqualRow per row: appendFrame builds a dirty-row bitset
    (rowBits) with render.Buffer.EqualRow, skips unchanged rows in the cell
    loop, and runs scroll detection only when at least one row is dirty, so
    an idle frame costs height row comparisons and zero bytes
  scroll detection hashes stride-sampled row samples (32 samples per row,
    stride max(1, (width+31)/32)) into two fixed arrays, skipping color
    terms under the monochrome profile
  tests: EqualRow guard contracts (nil receiver/argument, width mismatch,
    out-of-range y), the post-scroll re-mark regression, and backward
    cursor-rewind coverage

Review status:
  One adversarial correctness pass over the encoder changes at 940783a
  delivered: no correctness bugs found, three findings, all byte-cost:
    - stride-sampled hashing can accept a shift whose rows are not truly
      equal, or a different shift with an equal score; the per-row diff
      loop repairs every row the hash-based region got wrong, so only the
      byte count can vary
    - the dirty bitset re-walks rows through EqualRow after the hash
      sample, inheriting a raw byte-compare cost
    - the dirty-gate short-circuit makes tracked/repaint combinations
      harder to reason about at the margins
  A mutation campaign over the same code produced the results above. The
  code-level checks in this file are self-review, the mutation results,
  and the gate.

Known limits, deliberately not addressed here:
  stride-hash shift acceptance is byte-cost, not correctness (see review)
  capability negotiation is not implemented; profiles are fixed at startup
  the idle-scan cross-package overhead (height EqualRow calls per frame)
    is not yet documented
  minScrollRows is 3, so shifts of 1-2 rows repaint instead of scrolling
  frames taller than maxTrackedRows (512) fall back to full repaint
  keyboard scrolling does not bubble between nested viewports
  a 64 KiB single-line field still costs tens of milliseconds per edit
