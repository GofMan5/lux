Doc-truth cross-check (every claim traced to code before writing):
  - flags pushed = 0b11: kittyEnter "\x1b[>3u" (backend.go); pop CSI < u
    unchanged and still leads the restore on every exit path (6.1)
  - KeyEvent Action/Repeat, kitty release Repeat=0: event.go kittyKey
  - release filtering: app.go run loop (before applyEvent), opt-in
    WithKeyReleases; ui gates check Action == ActionRelease only, so
    ActionRepeat passes (context.go, textinput.go, controls.go, scroll.go)
  - modifier bits: shift 1, alt 2, ctrl 4, super 8, hyper 16, meta 32,
    caps-lock 64, num-lock 128 (decodeModifier; event.String order)
  - kitty sends PUA CSI u even in pure legacy mode (kitty spec RST):
    kittyFunctional is mandatory, not enhancement-gated — 57344-57357,
    57427, 57441-57454, 57455-63743 stay unknown
  - keypad normalization: digits/punctuation as runes, KP_ENTER = Enter,
    KP arrows = arrows; KP_BEGIN unknown
  - event-type grammar: colon sub-parameter of field 2 is canonical;
    trailing semicolon field is the lenient pre-standard spelling; junk or
    out-of-range values decode unknown (kittyEventType, parseKittyKey)
  - Enter/Tab/Backspace release absence at flag 0b11 is the spec's
    shell-safety exception; a rogue release still decodes honestly
  - 0x08 = Ctrl+Backspace (kitty truth); xterm's Ctrl+H spelled the same
    byte is indistinguishable on the legacy path — divergence documented
  - CSI 29 ~ = Menu (kitty) vs F16 (xterm): kitty wins, documented
  - \x1b\x1b + CSI/SS3 = Alt-modified arrow-family (parseEscape recursion,
    depth 1); junk (mouse/paste/focus shapes) behind a doubled escape
    decodes unknown; lone pair surfaces as two escapes 35 ms apart
    (flushEscape drops one 0x1b per tick)
  - Scoped shortcuts match Code/Rune/Mod and ignore Action and Repeat
    (sameShortcutKey); Is() subset matching tolerates lock bits
