Stage 8, slice 6 — Theme and Context override
Date: 2026-10-08
Headline: one palette (Text, Muted, Accent, Danger) resolved per Context; no
global mutable style table anywhere.

Scope
-----
- ui/theme.go: Theme struct (four render.Style roles), DefaultTheme() as a
  FUNCTION so no shared table can be mutated, Context.UseTheme/Theme with
  mu-guarded read/write and a themeSet flag (zero-value Context stays
  DefaultTheme), themedStyle(explicit, role, base) resolution helper.
- ui/context.go: theme + themeSet fields.
- Wiring (zero-value style fields resolve through roles; explicit always
  wins; zero role falls back to the widget default):
  * gauge.go: Fill→Accent, Track→Muted
  * spinner.go: Style→Accent
  * sparkline.go: Fill→Accent
  * tabs.go: Selected→Accent, Normal→Muted, DisabledStyle→Danger
  * table.go: Normal→Text, Header→Muted (underline kept in every branch),
    Selected→Accent, DisabledStyle→Danger
  * select.go: Normal→Text, Popup→Muted, OptionNormal→Text,
    OptionSelected→Accent, DisabledStyle→Danger
  * checkbox.go: Normal→Text, marker run→Accent (Normal is its explicit
    override; label stays Text), DisabledStyle→Danger — the marker/label
    split is one extra Text call with explicit cell math
  * checkbox.go RadioGroup: Normal→Text, Selected→Accent,
    DisabledStyle→Danger
  * tree.go: Normal→Text, Selected→Accent, DisabledStyle→Danger
- DefaultTheme is attributes-only: Muted=Dim, Accent=Bold, Danger=Reverse,
  Text zero. Monochrome terminals and redirected output survive; color
  themes are opt-in values.
- Default visuals change where zero styles were painted (documented in
  README/CHANGELOG): selected tabs/rows bold, unselected tabs and headers
  dim (header keeps underline), gauge fill / spinner / sparkline bold,
  disabled reverse-video, checkbox markers bold while labels stay plain.
