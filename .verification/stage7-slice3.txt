Mechanism (pinned by tests, traced to code):
  - probe: the startup write appends the 2027 query after the 9001
    query; parseProbeReply's DECRPM arm answers it; the early-exit
    condition now also waits for a 2027 verdict (status 0 counts as
    "answered" — rejected, not awaited)
  - verdicts: status 1 (set), 2 (reset), 3 (permanently set) recognize;
    status 0 (not recognized) and 4 (permanently reset — the set-mode
    write would be a no-op, same reasoning as 2026/1016/9001) reject;
    silence leaves the mode off (probeUnknown -> applyProbeFeatures
    keeps false)
  - tri-state override: unicodeCoreOpted is nil by default (probe
    decides), terminal.UnicodeCore(true) forces on despite silence,
    terminal.UnicodeCore(false) forces off despite a positive answer —
    the escape hatch for a lying report; LUX_TUI_PROBE_TIMEOUT=off kills
    the whole negotiation including this verdict
  - latch-before-enter: Open resolves the latch (features verdict,
    then the option override) BEFORE the enter write is composed, so an
    option override never races the probe
  - enter order: base enter (alt screen et al.) -> kitty -> win32 ->
    2027 LAST, one write; leave order is LIFO: 2027 FIRST on every exit
    path (Close's re-derivation uses the snapshot latched at enter, not
    the mutable fields, so the reset cannot be lost after mutation)
  - suppression: defaultBackendOptions appends terminal.UnicodeCore
    (false) exactly when settings.widthPolicy != render.WidthPolicy{}
    — one stream follows one width authority; WithWidthPolicy doc says so
  - multiplexer gate: 2027 is output-family, so the tmux/screen gate
    does NOT downgrade it (a multiplexer that ignores the set-sequence
    cannot corrupt input decoding — ignored writes are harmless, unlike
    a forged input-family claim); TestTmuxKeepsUnicodeCoreClaim pins
    this against the same tmux fixture that downgrades kitty/pixel/win32
  - measurement: unchanged by design — uniseg segmentation + 18.0.0
    overlay (+ optional policy) remains the single width authority; 2027
    converts coincidental agreement into a specified contract
