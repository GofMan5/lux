Integration findings (documented, no engine changes needed)
-----------------------------------------------------------

1. ssh -tt from a piped client requests a 0-row/0-col pty (no local
   terminal to size from). A 0x0 canvas paints nothing: app runs, serves
   input, exits 0, zero frame bytes. Not a lux defect: backend.Size()
   reports 0x0 without error and app.go skips 0-cell frames by design;
   WithFallbackSize does not apply (no error, and a pty exists). Fix on
   the user side: `ssh -tt host 'stty rows 24 cols 80; my-tui-app'`.
   Proven: DA1-reply injection changed nothing; stty alone fixed it.
2. Keystrokes at t=0 race MakeRaw: the cooked line discipline eats
   0x11/0x13 as XON/XOFF. Reproduced deterministically under strace
   (slower startup). Lanes send scripted keys after raw mode is up.
   Documented for test-harness authors in the matrix README.
