API (verified by e2e on a real kernel, not by inspection):
  - WithSuspend(false): the handshake never runs, ISIG stays off, and
    the 0x1A byte reaches the model as an ordinary Key event a custom
    binding can own (pinned by TestSuspendInterceptOptOutRestoresTheKey).
  - Interception order: a ctrl+z keystroke NEVER reaches the model as a
    Key; the model sees Suspend (before the leave bytes) and later
    Resume. With the handshake raced by a probe, the model sees Suspend
    then the replayed Key — never a spurious Resume.
  - e2e byte truth: exactly one leave sequence on a plain exit
    (enter ... leave), title pop \x1b[23;0t as the FINAL bytes on the
    wire, cursor shown, leave bytes precede the pop. Suspend+close
    writes leave exactly twice (idempotent, test-pinned), titleSet
    exactly twice (open + resume).
  - Shell oracle: under `sh -i` as session leader, typing 0x1a produces
    the shell's own "Stopped" line — proof of a real waitpid-visible
    stop of the process group. `fg` resumes: S:1 R:1 to the model, full
    repaint, title re-pushed. A second SIGTSTP raised straight at the
    stopped job is discarded (SIGCONT flushes pending stop signals).
  - Probe-race replay survives a real kernel input buffer: keystrokes
    that race the DA1/kitty probe are delivered after it, not eaten.

Stop-chain facts discovered while making the lane green (mirrored in
ROADMAP/README/COMPATIBILITY):
  (a) An orphaned process group has no parent to waitpid it, so the
      kernel DISCARDS its stop signals — a direct child lane can never
      observe a stop; the shell lane (sh -i as session leader) is the
      only honest oracle.
  (b) The Go 1.21+ runtime swallows a self-raised TSTP after
      Notify->Reset — the A2 design (never Notify TSTP at all) exists
      because of this.
  (c) Linux flushes the master's pending unread input when the last
      slave fd closes: a child that exits immediately loses its final
      Close writes — hence childapp's 150 ms post-Run slave hold.
  (d) SIGCONT discards pending stop signals: raising a second SIGTSTP
      straight at a stopped job is safe — fg's SIGCONT throws it away,
      so exactly one suspension is delivered.
  (e) The wire ends with the title pop after the leave bytes — the
      shipped protocol order is now e2e-pinned, not just unit-pinned.
